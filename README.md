# task-manager
Самый лучший менеджер задач
Проект ведётся согласно модели github flow.
- Прямые коммиты в основную ветку запрещены. Все изменения попадают в неё через
  pull/merge request.
- Каждый pull request должен быть просмотрен и одобрен минимум одним другим
  участником команды.
- Каждый участник команды должен выступить и автором, и ревьюером. Распределение
  вклада проверяется по истории репозитория.
- В описании pull request указываются идентификаторы требований FS и разделов HLD,
  которые он реализует.
